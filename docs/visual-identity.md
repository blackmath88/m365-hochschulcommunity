# Open Layers — Visual Working Identity

**Status:** working identity, not an official brand.

## Idea

Open Layers describes the M365 Hochschulcommunity as a shared working and knowledge layer between autonomous institutions.

> Many autonomous institutions — one shared layer.

The identity should feel like research, infrastructure and editorial design rather than a software vendor, association or marketing campaign.

## Mark

The central visual element is a modular chevron built from independent translucent parts. The modules remain visible; only their overlap creates a shared direction.

The chevron represents:

- autonomy
- connection
- exchange
- modularity
- openness
- forward movement

It is a flexible graphic element, not a mandatory corporate logo. It can appear small beside the wordmark, cropped at page edges, enlarged on covers, or broken into modules for diagrams and project markers.

## Wordmark

**M365 Hochschulcommunity**

M365 is the compact technical anchor; Hochschulcommunity carries the identity.

Optional working claim:

> Gemeinsam weiter mit offenen Lösungen.

## Typography

Primary: **Manrope**. Fallback: Helvetica Neue / Arial / sans-serif.

Strong hierarchy, compact headlines, calm body text. Typography should carry more weight than decorative UI elements.

## Colours

- Deep Green `#0F4D3B`
- Jade `#2E7D6B`
- Mint `#88BDA7`
- Soft Green `#D7E8E1`
- Tint `#EEF5F2`
- Lavender `#E9E6F3`
- Dark Navy `#172B3A`
- White `#FFFFFF`

Use transparency and overlap inside the green family. Avoid a Microsoft-blue identity, generic SaaS gradients or decorative colour noise.

## Layout

Swiss/editorial rather than dashboard-like:

- generous white space
- clear grids
- thin rules
- precise alignment
- few deliberate colour fields
- no floating SaaS cards
- no excessive rounded corners

The chevron is allowed to break the grid and introduce movement, but should not become wallpaper.

## Image language

Prefer architecture, infrastructure and real higher-education environments. Use calm, graphic crops, often monochrome or lightly desaturated. Avoid staged teamwork stock photography.

## Governance language

Current coordination:

**Kai Boschung · Lysann Deutschmann · Achim Imboden**

Use `Coordination` or `Coordinating Board` discreetly. The visual language should communicate stewardship, not hierarchy or ownership.

## Print

The two primary materials are HTML documents with exact A4 print layouts. Screen and print are views of the same source content. The canonical artefact stays editable in the repository; PDF is an export.
